# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to:

**Email:** support@draculcybersec.com

Do **not** create a public GitHub issue for security vulnerabilities.

## Scope

The following Base Mainnet contracts are in scope for this project:

1. **DRAC Token** — `0xb193cFE2E4A807Ff3dF920139bfA3785F8094c70`
2. **Timelock** — `0x78D17d3bb3Bb843462DT67278622817315Faa6e76`
3. **Governor** — `0xF30d56332d575E1F37EB89841C157713C5968Ac4`
4. **Staking** — `0xdC5b4D7707303Cafb4308E42e3E6cB1813cC03cb`
5. **Team Vesting** — `0x6Ec9881FCBf02e13374239653eaDC9573728681f`

## Important Rules

- **Never include secrets, private keys, seed phrases, keystore files, passwords, recovery codes, auth tokens, private RPC credentials, or .env files** in any report.
- Include clear reproduction steps and the minimum amount of information needed to verify the issue.

## Audit Status

Internal testing and static analysis do not constitute an independent third-party audit. There is currently no named, publicly available independent audit report for these contracts.
